# GPT-5.6 Sol portfolio regression

Date: 2026-07-16

This run evaluates the current public Human vs GAIA manifest with the LMS
scenario excluded. The scenario IDs, goals, URLs, and order were not edited for
the run or its blocked-only rerun.

## Protocol

```bash
python scripts/materialize_gaia_vs_human_suite.py \
  --exclude-site-key inu_lms_hvh \
  --output artifacts/benchmarks/gaia_vs_human_portfolio_30.json

python scripts/run_goal_benchmark.py \
  --suite artifacts/benchmarks/gaia_vs_human_portfolio_30.json \
  --provider openai \
  --model gpt-5.6-sol \
  --runtime-isolation warm-process-cold-state \
  --qa-mode off \
  --output-dir artifacts/benchmarks/portfolio-v020-gpt56-sol-30
```

- Codex CLI: 0.144.4
- Authentication: local Codex OAuth session
- Browser: embedded OpenClaw runtime
- Repeats: 1
- Scenarios: 30
- Runtime policy: warm browser process, cold site state between scenarios

Raw artifacts are generated locally under `artifacts/` and are intentionally
ignored by Git. This report preserves the aggregate results and failure audit.

performance budget: actor prompts accounted for 6.14M of 6.61M prompt
characters.

## Blocked audit

The four blocked scenarios were rerun once without changing their source
definitions. All four reproduced the same blocking condition.

| Scenario | First run | Rerun | Observed cause |
| --- | ---: | ---: | --- |
| `GRAFANA_001_LOGIN_AND_BENCHMARK_DASHBOARD` | 139.82s | 118.37s | The fixed Grafana host returned `ERR_CONNECTION_REFUSED`. |
| `NAMU_001_REALTIME_TOP5_ARTICLE_STRUCTURE` | 4.55s | 3.99s | A CAPTCHA/security verification gate appeared immediately. |
| `LOTTEWORLD_002_GROUP_RESERVATION_PRODUCT_COUNT` | 164.78s | 82.91s | June 3 was in the past and disabled; month traversal was stopped as repeated action. |
| `NOL_002_INCHEON_SONGDO_LOWEST_PRICE_SORT` | 75.23s | 74.27s | June 2 was in the past and absent from the selectable calendar. |

This distinction matters: there were no non-blocked agent failures, but the
user-visible suite still completed only 26 of 30 scenarios. A maintained
benchmark should self-host fixed fixtures and express calendar goals relative
to the run date.

## Historical comparison

The preserved 2026-05-31 baseline used `gpt-5.5` with the same runtime
isolation policy and reported 30/30 SUCCESS, 76.50s mean, 61.12s median, and
231.04s p95. It is not a strict model A/B:

- the historical suite contains `CYBER_001_LSM_LOGIN_AND_CHAT`;
- the current public suite replaces it with
  `COUPANG_002_PROTEIN_SHAKE_36_COUNT_VARIANT_COMPARE`;
- live sites, dates, account state, and anti-bot surfaces changed between runs.

For the 29 scenario IDs shared by both artifacts:

| Shared-set metric | GPT-5.5 historical | GPT-5.6 Sol current | Change |
| --- | ---: | ---: | ---: |
| SUCCESS | 29/29 | 25/29 | 4 current external/time blockers |
| Mean duration, all outcomes | 78.53s | 67.67s | -13.8% |
| Median duration | 61.97s | 58.45s | -5.7% |
| p95 duration | 231.04s | 139.82s | -39.5% |
| Total steps | 169 | 168 | -1 |

The current run is faster in this field regression, but the result cannot be
attributed to the model alone. The defensible conclusion is narrower: under
the current live-site conditions, GPT-5.6 Sol preserved 100% primary success,
recovered all three recoverable action failures, and reduced observed latency
while exposing four deterministic environment/scenario blockers.
